# MegaBank Unix System Administration Challenge

## 🎓 Unix/Linux Skills Assessment

This is a **Unix system administration simulation** focused on bash scripting, text processing, and Linux troubleshooting skills.

See `SCENARIO.md` for the full mission details.

## 🛠️ Unix Skills Required

- **Bash Scripting**: Debug and fix shell scripts
- **Text Processing**: Use grep, sed, awk to manipulate files
- **File Permissions**: Fix ownership and permission issues
- **Process Management**: Handle running processes and signals
- **System Tools**: Use find, ps, netstat, lsof, etc.
- **Environment Variables**: Manage and debug shell environments
- **Log Analysis**: Parse and analyze system logs

## Quick Start

```bash
./start_app.sh    # Try to start the system
```

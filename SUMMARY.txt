================================================================================
                        BUGS INTENTIONALLY PLACED
================================================================================

Students must fix 8 Unix-related issues:

1. File Permissions       - Scripts not executable (chmod needed)
2. DOS Line Endings       - CRLF instead of LF (dos2unix needed)
3. Wrong Python Command   - Uses 'python' not 'python3' (sed needed)
4. Database Password      - Missing '!' character (sed needed)
5. SQL Syntax Errors      - Missing ; and ) (sed needed)
6. Wrong File Path        - Incorrect path (sed needed)
7. Variable Name Error    - Typo in variable (sed/grep needed)
8. Wrong Port Number      - Checking wrong port (sed needed)

ALL require Unix command-line tools to diagnose and fix!
